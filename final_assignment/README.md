# Hungry Animals: Snack Drop

A fast-paced 2D arcade game built with Python and Pygame. Choose your animal, catch its favourite food and avoid everything else.
Created as a final assignment for the TechBasics 1 seminar.

---

## The Game

Food falls from the top of the screen. Move your animal left and right along the bottom to catch the snacks it likes and dodge the ones that belong to the other pets.
The higher your score, the faster the food falls.

---

## Requirements
- Python 3.11 or newer
- Pygame

Install Pygame

## How to Start

1. Make sure the `images` folder is in the same directory as `Hungry_Animals.py`.
2. Run the file: python Hungry_Animals.py

---

## Controls

Choose your animal (start screen) : 1-5
Move your animal : Left / Right arrow
Pause and continue : P
Restart after game over : R
Quit the game : Q

---

## The Animals favourite food

Monkey: Banana
Dog: Bone
Frog: Fly
Cat: Fish
Bunny: Carrot

---

## Rules

- **Catch your favourite food** → +1 point
- **Catch the wrong food** → −1 point and −1 life
- **Miss your favourite food** → −1 point
- **Score drops below zero** → −1 life, score resets to 0
- **No lives left** → game over

You start with 3 lives. Every 5 points the food falls faster, so the game gets harder the better you play.

Your best result is saved in `highscore.txt` and stays there the next time you play.
